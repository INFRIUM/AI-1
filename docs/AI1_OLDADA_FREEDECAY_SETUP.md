# B′ Old ADA 자유 감쇠 고유진동수 감시 — 실행 설정 (실행 전 기록)

작성일: 2026-11-27 · 작성: AI① · 코드: `src/ai1_oldada_freedecay.py` · 근거: `docs/AI1_MODEL_CARDS.md` 7절 (자유 감쇠 확인)

B(TCN-GAT, 차량 통과 구간)는 v1·v2 모두 통과하지 못했다. 자유 감쇠 확인에서 손상에 따른 고유진동수 변화가 보여, 이를 감시하는 단순 모델을 B의 대체 후보(B′)로 시험한다.

**이 시험은 개발 시험이다.** 7절 확인에서 손상 주행까지 이미 봤고, 아래 임계값(1%)도 그 결과(정상 차이 0.4% 이하, DMG2·3 1.8% 이상)를 보고 정했다. Old ADA 결과를 원 교량 독립 검증으로 쓰지 않는다. 결과를 보고 설정을 바꿔 다시 돌리지 않는다.

## 1. 입력
- 주행별 진출 후 1–31초 자유 감쇠 (`config.OLD_ADA["free_decay_s"]`).
- PSD: 선형 추세 제거, Welch 2048점, nfft 16384, 센서 PSD 합. 봉우리는 포물선 보간.

## 2. 특징 (주행당 2개)
| 특징 | 탐색 대역 | S8 센서 | S2 센서 (HW와 같은 배치) |
|---|---|---|---|
| f1 | 0.8–1.2 × f1_ref | A1–A8 | A1(L/4), A3(L/2) |
| f2 | 1.9–2.6 × f1_ref | A1·A2·A4·A5 (같은 쪽, 중앙 아님) | A1(L/4)만 (L/2는 2차 모드 마디) |

- f1_ref = 2.93Hz (`config.OLD_ADA["f1_hz"]`, 정상 학습 주행에서 정함). 대역을 f1 비율로 정해 HW에 같은 규칙으로 옮긴다.
- f2에서 A3·A6–A8을 빼는 이유: 6.26Hz 다른 모드가 섞여 일부 정상 주행에서 f2를 잘못 잡는다 (7절).

## 3. 기준·점수·임계값
- 기준: INT40 학습 주행 1–4의 f1·f2 평균 (μ1, μ2).
- 점수: 주행별 max(|f1/μ1 − 1|, |f2/μ2 − 1|) × 100 [%].
- 임계값: **1.0%** (점수 > 1.0%이면 이상). 개발 시험용 값이다. HW에서는 여러 날 정상 데이터의 점수 분포로 다시 정한다.
- INT40 5–7(기존 임계값 역할 주행)은 점수만 보고한다.

## 4. 보고 항목 (주행 단위)
- 시험 정상 INT40 8–10 오경보 (주행 수 / 3).
- DMG1·DMG2·DMG3 각각과 전체 탐지율, DMG2·3 합 탐지율.
- AUC (시험 정상 INT40 8–10 대 DMG1–3 전체, 점수 기준).
- 보고만: INT40 5–7, INT30, INT50, RCV의 이상 비율. 주행별 f1·f2·점수 표.
- S8, S2 둘 다.

## 5. 판단 기준 (미리 정함)
- B와 같은 기준: 시험 정상 오경보 ≤ 5% (3개 중 0개) 그리고 DMG 전체 탐지 ≥ 80%이면 "개발 시험 통과", 아니면 "개발 시험 통과 못 함".
- DMG1(반 절단)은 7절에서 고유진동수 변화가 없었다. DMG1을 놓치면 DMG 전체 탐지는 최대 20/32 = 62.5%라 기준을 못 넘는다. 그래도 기준은 바꾸지 않고, DMG2·3 탐지율을 따로 적는다.
- S2 결과는 HW 성능 근거가 아니다. 센서 2개로 같은 계산이 되는지 확인하는 용도다.

## 6. HW로 옮기는 규칙 (기록만)
| 항목 | Old ADA | HW |
|---|---|---|
| 가진 | 차량 통과 후 자유 감쇠 | 같은 위치·세기 타격 후 자유 감쇠 (toHW 제안) |
| f1 탐색 | 0.8–1.2 × f1_ref | 0.8–1.2 × f1_HW |
| f2 탐색 | 1.9–2.6 × f1_ref, L/4 쪽 센서 | 같은 비율 (HW에서 f2/f1 확인 후 조정), L/4 센서 |
| 기준 | 정상 4주행 평균 | HW 초기 정상 여러 날 평균 (온도 기록 포함) |
| 임계값 | 1.0% (개발 시험용) | HW 정상 점수 분포로 다시 계산 |

## 7. 실행 순서
