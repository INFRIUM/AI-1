# AI① 전문 이상탐지 모델 적용 조건표

작성일: 2026-11-26 · 작성: AI①

새 교량에 맞는 모델을 고르는 기준이다. 모델을 만들거나 검증할 때마다 이 표를 고친다.

## 1. 고르는 순서
1. 새 교량의 센서 종류·수·위치, 샘플링, 가진 조건을 확인한다.
2. 조건이 맞는 모델만 남긴다.
3. 남은 모델 중 검증 상태가 "통과"인 것을 고른다.
4. 그 교량의 정상 데이터가 필요한 만큼 모이면 기준값을 다시 계산하고 적용한다.
5. 맞는 모델이 없거나 정상 데이터가 부족하면 판정 보류로 둔다.

옮기는 것은 방법(특징, 점수 계산)이다. 정상 기준과 임계값은 새 교량의 정상 데이터로 다시 계산한다.

- 비교 기준: Isolation Forest (정상 학습, 교량별 특징값). 다른 모델이 더 나은지 확인하는 용도다.
- 검증 상태: 통과 = 미리 정한 기준을 넘음 / 참고용 = 실행했으나 한계가 있음 / 미시행 = 아직 실행하지 않음.
- 현재 "통과"인 모델은 없다.

## 4. B. Old ADA TCN-GAT 논문 확인 (2026-11-26, 본문)
| 항목 | 논문 내용 |
|---|---|

- 실행 계획: 정상 주행을 주행 단위로 나눠 일부로 학습하고, 나머지 정상 주행에서 오경보를 함께 본다. Isolation Forest와 같은 구분으로 비교한다.
