# AI① 전문 이상탐지 모델 적용 조건표

작성일: 2026-11-26 · 작성: AI①

새 교량에 맞는 모델을 고르는 기준이다. 모델을 만들거나 검증할 때마다 이 표를 고친다.

## 1. 고르는 순서
1. 새 교량의 센서 종류·수·위치, 샘플링, 가진 조건을 확인한다.
2. 조건이 맞는 모델만 남긴다.
3. 남은 모델 중 검증 상태가 "통과"인 것을 고른다.
4. 그 교량의 정상 데이터가 필요한 만큼 모이면 기준값을 다시 계산하고 적용한다.
5. 맞는 모델이 없거나 정상 데이터가 부족하면 판정 보류로 둔다.

옮기는 것은 방법(특징, 점수 계산)이다. 정상 기준과 임계값은 새 교량의 정상 데이터로 다시 계산한다.

## 2. 모델별 조건
| 조건 | A. HBTA | B. Old ADA | C. Vänersborg | D. 함부르크 |
|---|---|---|---|---|
| 구조 | 강 트러스 철도교 | 강 트러스교 | 강 트러스 개폐식 철도교 | PC 박스 거더교 |
| 이상탐지 방법 | AR(5) 계수 + 마할라노비스 거리 제곱 | TCN-GAT 오토인코더 복원 오차 | 온도 보정 변형률 + Z 관리도 | 조건부 PCA + MEWMA 관리도 |
| 센서 종류 | 가속도 | 가속도 (진동) | 변형률 + 기온 | 변형률 + 온도 |
| 센서 수와 위치 | 40개 (바닥 아래 수직) 또는 35채널 (벽면) | 확인 필요 | 변형률 3개 (균열 근처) | 변형률 6개 |
| 샘플링 | 100Hz | 확인 필요 | 200Hz (파일 평균 사용) | 1시간 평균 |
| 가진 조건 | 진동기 노이즈 가진 | 차량·상시 진동 | 열차 운행 | 상시 (교통·온도) |
| 필요한 정상 기간 | 논문: 같은 날 정상만 사용 | 확인 필요 | 정상 파일 5개 (3.8–5.1℃) | 약 7개월 반 |
| 검증 상태 | 참고용 | 미시행 | 참고용 | 재현 어려움 |
| 알려진 한계 | 아래 3절 | 우리 자료의 정상 학습 주행 4개뿐 | 정답 구분이 순환적, 정상 5개 | 실제 손상 아님, 전체 감시 자료는 신청 필요 |
| 근거 | 직접 실행 (3절) | 논문 초록 | 논문 본문 | 논문 본문, 데이터 설명 |

- 비교 기준: Isolation Forest (정상 학습, 교량별 특징값). 다른 모델이 더 나은지 확인하는 용도다.
- 검증 상태: 통과 = 미리 정한 기준을 넘음 / 참고용 = 실행했으나 한계가 있음 / 미시행 = 아직 실행하지 않음.
- 현재 "통과"인 모델은 없다.
