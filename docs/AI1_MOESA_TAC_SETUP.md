# E1. Ponte Moesa 1-TAC (전달률 일치도) — 실행 설정 (실행 전 기록)

작성일: 2026-11-28 · 작성: AI① · 코드: `src/ai1_moesa_tac.py` · 근거: Garcia-Ramonda et al. 2025 (Ponte Moesa Campagnola benchmark), 전달률·TAC 절, 표 1·2, 그림 9–11

박스 거더용 전문 모델이 아직 없어 만든다. 가속도 센서 **2개 쌍**으로 계산하는 지표라 현재 HW(L/4·L/2 가속도 2개)에 같은 형태로 옮길 수 있다.

**이 시험은 개발 시험이다.** Ponte Moesa는 AI① 1차 모델 개발(2026-11-23)에서 DS2를 정상으로 두고 라벨과 결과를 이미 봤고, 논문 결과(1-TAC가 손상 단계를 구분)도 알고 있다. 독립 검증으로 쓰지 않는다. 결과를 보고 설정을 바꿔 다시 돌리지 않는다.

## 1. 논문 내용 (확인한 것)
- 3경간 PC 2실 박스 거더, 길이 93.5m. 4일(2019-11-26 – 29) 동안 손상을 단계적으로 넣으며 상시 진동·진동기 가진을 측정했다. 온도 기록은 없다.
- 고유진동수(SSI-COV, 그림 9)는 **손상에 거의 반응하지 않았다** (논문 결론). 수직 모드 4.9, 5.8, 7.3Hz.
- 손상 지표 1-TAC: 두 센서 사이 전달률 T_ab = G_ab / G_bb (교차 스펙트럼 ÷ 자기 스펙트럼), 3–12Hz. 기준 상태 DS2. 60초 구간. 2–25Hz 4차 Butterworth 대역 통과. 진폭 RMS 0–0.008g 구간만 사용 (환경·작업 진동 영향 감소). 손상 단계별 분포가 구분되고 DS5·DS7이 가장 크게 바뀌었다.
- 논문은 DS2 60초 구간을 **무작위로 섞어** 반은 기준, 반은 검증에 썼다. 시간대가 다른 정상으로 오경보를 따로 보고하지 않았다.

## 2. 센서와 쌍
- 고정 센서 1·2·3번 Z축 (모든 Setup에 있음). 1번 x = 14.5m (y = +3), 2번 x = 45.5m (y = −3), 3번 x = 78.5m (y = +3).
- 쌍: P12 (a = 1, b = 2), P23 (a = 3, b = 2), P13 (a = 1, b = 3). b가 기준(분모) 센서.
- 쌍 하나가 HW의 센서 2개(L/4, L/2)에 해당한다. 쌍별 결과를 따로 보고한다.

## 3. 측정 역할 (공식 측정 목록 `Ambient.txt`의 시각 그대로)
| 역할 | 상태 | 측정 | 시간 |
|---|---|---|---|
| 기준 (T_ref) | DS2 | AMB_10 | 26일 19:00 – 24:00 (밤) |
| 임계값 | DS2 | AMB_11 | 27일 00:00 – 05:05 (새벽) |
| **시험 정상** | DS2 | AMB_12–18 | 27일 09:13 – 17:00 (**낮, 다른 시간대**) |
| 보고만 | DS2 | AMB_5–9 | 26일 15:54 – 18:00 (기준 직전 저녁) |
| 보고만 | DS0·DS1 | AMB_1–4 | 26일 10:32 – 13:44 (DS2보다 손상 적음) |
| 손상 | DS3 | AMB_19–30 | 27일 18:00 – 28일 11:35 |
| 손상 | DS4 | AMB_31–33 | 28일 11:53 – 13:45 |
| 손상 | DS5 | AMB_34–36 | 28일 13:46 – 15:22 |

- DS2는 실제 무손상이 아니다 (철근 노출). 결과는 "DS2 대비 변화" 탐지로 읽는다 (AI② 기록 요청과 같음).
- 기준·임계값은 밤, 시험 정상은 낮이다. 시간대(온도·주변 작업)가 달라도 오경보가 적은지를 본다.

## 4. 계산
1. 측정마다 Z축 2–25Hz 4차 Butterworth 대역 통과 (양방향).
2. 60초 구간으로 자른다 (겹침 없음).
3. 구간 RMS: 쌍의 두 센서 중 큰 값이 0.008g(0.0785m/s²) 이하인 구간만 쓴다 (논문 규칙). 제외 비율을 역할별로 보고한다.
4. 구간 스펙트럼: Welch 2048점(10.24초), 50% 겹침, Hann.
5. T_ref = 기준 구간 G_ab 합 ÷ G_bb 합 (복소수), 3–12Hz.
6. 구간 점수 = 1 − TAC, TAC = |T_dᴴ T_r|² / ((T_dᴴ T_d)(T_rᴴ T_r)), 3–12Hz 복소 전달률 벡터.
7. 결합 점수 = 세 쌍 점수의 평균 (쌍별 점수도 따로 판정).
8. 임계값 = 임계값 역할 구간 점수의 **99% 분위수** (B v1에서 평균 + 3σ가 긴 꼬리로 커진 것을 반영).

## 5. 비교 모델 (같은 구간·역할)
| 모델 | 내용 |
|---|---|
| E1 1-TAC | 위 계산 |
| Isolation Forest | 쌍별 log|T| 3–12Hz 1Hz 구간 평균 9개 × 3쌍 = 27개 특징, 나무 300개, 기준 구간으로 학습, 임계값은 같은 규칙 |
| (보고만) 고유진동수 | 1·2·3번 Z PSD 합의 4.4–5.4Hz 봉우리 (수직 1차 4.9Hz), 기준 평균 대비 변화율 |W|. 임계값 같은 규칙. B2 방식이 박스 교량에서도 통하는지 보는 용도 |

## 6. 보고 항목
- 구간 단위: 시험 정상 오경보율, DS3–DS7 각각과 전체 탐지율, AUC (시험 정상 대 DS3–7).
- 쌍별(P12, P23, P13)과 결합 결과.
- 측정(AMB) 단위: 이상 구간 비율. 보고만 데이터(DS0·DS1, DS2 저녁)의 이상 비율.
- RMS 기준으로 제외된 구간 비율.

## 7. 판단 기준 (미리 정함)
- 결합 점수에서 시험 정상 오경보 ≤ 5% 그리고 DS3–7 전체 탐지 ≥ 80%이면 "개발 시험 통과", 아니면 "개발 시험 통과 못 함".
- E1이 Isolation Forest보다 결합 AUC가 0.02 이상 높지 않으면 "비교 기준보다 낫다는 근거 없음"으로 적는다.
- 쌍 하나(HW 형태)로도 기준을 넘는지 쌍별로 적는다. HW 성능 근거로는 쓰지 않는다.

## 8. HW로 옮기는 규칙 (기록만)
| 항목 | Ponte Moesa | HW |
|---|---|---|
| 센서 쌍 | 고정 센서 2개 Z축 | L/4(a), L/2(b) Z축 |
| 대역 | 3–12Hz (수직 1–3차 모드 포함) | HW 1차–3차 수직 모드를 포함하는 대역 (HW 고유진동수 확인 후 f/f1 비율로) |
| 진폭 제한 | RMS ≤ 0.008g (상시 진동) | HW 가진 세기에 맞춰 다시 정함 |
| 기준·임계값 | DS2 밤 | HW 정상 여러 날 |
- 가진 조건: 상시 진동(출력만)으로 계산하므로 입력을 잴 필요는 없다. 매번 같은 조건의 가진이면 더 안정적이다.
