# A2. HBTA 고유진동수 감시 (B2 규칙 이전) — 실행 설정 (실행 전 기록)

작성일: 2026-11-28 · 작성: AI① · 코드: `src/ai1_hbta_freq.py` · B2 설정 `docs/AI1_OLDADA_FREEDECAY_SETUP.md`, 결과 조건표 8절

B2(Old ADA 자유 감쇠 고유진동수, 임계값 1%)가 다른 트러스에서도 통하는지 본다. HBTA에서는 고유진동수 방식을 조정한 적이 없다. 모드는 **기준 정상 측정만** 보고 자동으로 고르고, 임계값 1%는 B2에서 그대로 가져온다. 결과를 보고 설정을 바꿔 다시 돌리지 않는다.

- 주의: HBTA 손상 라벨과 A 결과는 이미 봤다. 다만 이 방법의 설정(모드 선택 규칙, 대역, 임계값)은 HBTA 손상 측정을 보지 않고 정했다.
- 이번 설정을 정하려고 본 것: 기준 정상(UDS _01) 5개 측정의 스펙트럼 봉우리만 (Y 가진 3.1·7.2Hz, Z 가진 6.8Hz 등).

## 1. 데이터
- `hbta/data_100Hz.h5`, 100Hz. 측정마다 시작 90초 이후 전체 (A와 같은 시작점).
- 가진 조건 5가지: NM_P2_Z(랜덤), SM_P1_Y, SM_P1_Z, SM_P2_Y, SM_P2_Z(스윕). 같은 조건끼리만 비교한다.

| 역할 | 측정 | 날짜 |
|---|---|---|
| 기준 | 조건마다 UDS `_01` | 2020-09-23 (P1) / 09-27 (P2) |
| **시험 정상 (다른 날)** | 조건마다 UDS `_02` | 2020-09-22 |
| 손상 | 조건마다 DS1–DS8 `_01` (40개) | 09-23 – 09-28 |

## 2. 센서
| 이름 | 채널 | 용도 |
|---|---|---|
| S2 | AG03, AG05 (벽면, 0.30L·L/2), 가진 방향 축 (Y 또는 Z) | HW와 같은 수 |
| SAG | AG01–AG18 벽면, 가진 방향 축 (Y는 AG09 제외, A와 같음) | 많은 센서 |

## 3. 특징
1. 채널마다 선형 추세 제거 → Welch 4096점(40.96초), nfft 32768 → 채널별 최대값으로 나눈 뒤 합.
2. **모드 선택 (기준 측정에서만)**: 1–30Hz에서 prominence ≥ 0.05인 봉우리 중 가장 큰 2개 → f_a, f_b.
3. 각 측정에서 f_a·f_b의 ±5% 대역 안 최대 봉우리 (포물선 보간).

## 4. 점수·임계값·판정
- 점수 = max(|f_a/f_a,ref − 1|, |f_b/f_b,ref − 1|) × 100 [%].
- 임계값 **1.0%** (B2 그대로). 점수 > 1.0%이면 이상.
- 시험 정상 오경보 = 5개 조건의 UDS `_02` 중 이상 판정 수. 손상 탐지 = 40개 중 이상 판정 비율. DS1–4(국부)와 DS5–8(전체 거동) 탐지율, 상태별 탐지, AUC를 함께 보고.

## 5. 판단 기준 (미리 정함)
- 시험 정상 오경보 ≤ 5% (5개 중 0개) 그리고 손상 전체 탐지 ≥ 80%이면 "통과", 아니면 "통과 못 함".
- S2(센서 2개) 결과를 따로 적는다.
- 비교: A(AR+MSD)의 다른 날 정상 시험(오경보 96–100%)과 비교해 적는다. Isolation Forest는 조건마다 기준 측정이 1개라 학습할 수 없어 하지 않는다.
- 측정 날짜 기온이 9–22°C로 다르다. 기온 기록은 보고만 한다 (보정하지 않음).
