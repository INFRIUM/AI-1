# C1. Vänersborg 개폐 재하 변형률 감시 — 실행 설정 (실행 전 기록)

작성일: 2026-11-28 · 작성: AI① · 코드: `src/ai1_vanersborg_strain.py` · 근거: Khan et al. 2026 (ITI, liag010), Leander et al. 2023 (Data in Brief 51:109729)

변형률 + 온도 전문 모델(C)이다. 현재 HW에는 변형률 센서가 없어 HW 적용은 판정 보류(④)이고, 전문 모델 목록을 채우는 용도다.

**이 시험은 개발 시험이다.** 설계 중 파일 4개(정상 2개, 균열 진전 중 1개, 진전 후 1개)를 열어 구조를 확인하다가 손상 파일의 값을 봤다 (SG9 열림−닫힘 차이: 정상 276·295, 진전 중·후 476·493µm/m). 독립 검증으로 쓰지 않는다. 결과를 보고 설정을 바꿔 다시 돌리지 않는다.

## 1. 논문 방법과 문제점
- Khan 2026: 닫힘 상태 SG10 파일 평균을 기온으로 1차 회귀 보정(α = 39.2µm/m/°C)하고 Z ≥ 2이면 경보. 56개 파일에서 정밀도·재현율 1.00으로 보고.
- 문제 1: 회귀에 쓴 정상 파일이 처음 5개(2월 20–21일, 기온 3.8–5.1°C)뿐이고, 이를 −8 ~ +8°C로 외삽했다.
- 문제 2: 나머지 51개를 모두 손상으로 두었다. 손상 진행 시작(2월 22일)은 논문 방법의 첫 경보 시점이다 → 정답이 모델 결과에 의존한다.
- 확실한 사건은 **2023-03-09 23:45 균열 진전**(SG9·SG10, A5에 기록) 하나다.

## 2. 데이터와 정답
- `vanersborg/DiB.zip` 64개 CSV (교량 개폐 기록, 200Hz). 이름 순(시간 순)으로 번호 0–63.

| 역할 | 파일 번호 | 상태 |
|---|---|---|
| 학습 (기준 적합) | 0–19 | 균열 진전 전 |
| 보정 확인 | 20–39 | 균열 진전 전 (오경보 보고) |
| **시험 정상** | 40–56 | 균열 진전 전 (오경보 판정) |
| 손상 | 57 (진전 중, 2023-03-09T23:45:25), 58–63 (진전 후) | 균열 진전 |

- 기존 `config.VANERSBORG["roles"]`와 같은 번호다. 진전 전 파일도 균열이 이미 있었을 수 있다 (진전 전 = "진전 사건 전"으로 읽는다).

## 3. 특징 (파일마다)
- 경사계 ch_25로 상태 구분: **닫힘** = 파일 최대값 − 1° 이상, **완전 열림** = 파일 최소값 + 1° 이하.
- 변형률: SG9(ch_9), SG10(ch_10) (균열 옆, 논문과 같음). SG11은 부호가 바뀌는 등 값이 튀어 보고만 한다. SG12는 −1,000,000 고정이라 쓰지 않는다.
- 기온: ch_30 닫힘 구간 평균.
- **F_open (주 특징)**: Δ = 완전 열림 구간 중앙값 − 닫힘 구간 중앙값 [µm/m]. 같은 자중을 반복해서 거는 재하 응답. 같은 파일 안에서 빼므로 온도 영향이 대부분 상쇄된다.
- **F_static (논문식 비교)**: 닫힘 구간 평균 [µm/m].

## 4. 온도 보정·점수·임계값
- 특징마다 학습 파일(0–19)로 `특징 = a + b × 기온` 최소제곱 → 잔차 r. σ = 학습 잔차 표준편차.
- 센서별 Z = r / σ. 파일 점수 = max(|Z_SG9|, |Z_SG10|).
- 임계값 **Z\* = 3** (관리도 3σ).
- 모델:

| 모델 | 특징 |
|---|---|
| C1 | F_open (SG9, SG10) |
| C1-static | F_static (SG9, SG10), 같은 보정·점수 |
| Isolation Forest | [F_open SG9·SG10, F_static SG9·SG10, 기온], 학습 파일로 적합, 임계값 = 보정 확인 파일 점수의 최대값 |
| (보고만) 논문 재현 R0 | F_static SG10, 처음 5개 파일로 회귀, Z ≥ 2 → 진전 전 파일 중 경보 비율 |

## 5. 판단 기준 (미리 정함)
- 시험 정상(40–56, 17개) 오경보 ≤ 5% (0개) 그리고 손상(57–63, 7개) 탐지 ≥ 80% (6개 이상)이면 "개발 시험 통과", 아니면 "통과 못 함".
- C1이 C1-static·Isolation Forest보다 AUC(시험 정상 대 손상)가 0.02 이상 높지 않으면 "재하 응답 특징이 낫다는 근거 없음".
- 논문 재현 R0의 진전 전 오경보 비율을 적는다 (논문은 이 파일들을 손상으로 봤다).

## 6. HW 의미 (기록만)
- 현재 HW는 변형률 센서가 없어 C1은 판정 보류(④).
- 일반 원칙: **매번 같은 하중을 거는 반복 재하의 응답 변화**는 온도·환경 영향을 같은 기록 안에서 상쇄할 수 있다. HW에서 같은 추·같은 위치 재하를 반복하면 가속도(정적 기울기·응답)로도 같은 원칙을 쓸 수 있다.
