# Old ADA TCN-GAT v2 실행 설정 (실행 전 기록)

작성일: 2026-11-27 · 작성: AI① · 근거: Ni et al. 2025, Sensors 25:6724, 3.2·4.3절, 그림 13b·16 · v1 설정: `docs/AI1_OLDADA_TCNGAT_SETUP.md` · v1 결과: `results/public/oldada_tcngat/`

v1(2026-11-27, 1회)은 손상 탐지 6% 이하, AUC 0.52–0.64로 통과하지 못했다. v1 결과는 그대로 둔다. v2는 **다리 치수·센서 위치·고유진동수를 논문과 데이터에서 확인해 넣고, HW에 같은 규칙으로 옮길 수 있게** 설정을 다시 정한 것이다. 이 문서를 커밋한 뒤 합성 점검 → 실제 데이터 1회 실행한다. 결과를 보고 설정을 바꿔 다시 돌리지 않는다.

## 1. 교량과 센서 배치 (확인한 값)
- 교량: 길이 L = 59m, 폭 3.6m, 높이 8m 강 Warren 트러스 (논문 4.3.1절).
- 센서 좌표: 논문 그림 16의 인접 행렬(텍스트로 추출)과 A1 = L/4, A3 = L/2(기존 확인)로 정했다.

| 센서 | 트러스 | x/L | x [m] |
|---|---|---|---|
| A1 | 1쪽 | 0.250 | 14.75 |
| A2 | 1쪽 | 0.375 | 22.13 |
| A3 | 1쪽 | 0.500 | 29.50 |
| A4 | 1쪽 | 0.625 | 36.88 |
| A5 | 1쪽 | 0.750 | 44.25 |
| A6 | 2쪽 (y = 3.6m) | 0.375 | 22.13 |
| A7 | 2쪽 | 0.500 | 29.50 |
| A8 | 2쪽 | 0.625 | 36.88 |

- 근거 1 (그림 16 인접 행렬, 행 A1…A8): `11000100 / 11100110 / 01110111 / 00111011 / 00011001 / 11100110 / 01110111 / 00111011`. A1–A5가 한 줄로 이웃하고, A6·A7·A8이 각각 A2·A3·A4 맞은편이어야 이 행렬이 나온다. 간격은 L/8 = 7.375m.
- 근거 2 (모드 형상, 정상 학습 주행 INT40 1–4의 자유 감쇠만 사용): 1차 봉우리 세기 A1…A5 = 0.50, 0.89, 1.00, 0.85, 0.47로 sin²(πx/L) 예측값(0.50, 0.85, 1.00, 0.85, 0.50)과 맞다. 2차는 A3·A7(경간 중앙)에서 0으로 역대칭 모드의 마디와 맞다.
- 손상 위치: DMG1·2 = 경간 중앙 수직재 (A3·A7 위치), DMG3 = 5/8 지점 수직재 (A4·A8 위치).

## 2. 고유진동수 (정상 학습 주행에서만 확인)
- INT40 1–4회, 진출 후 1–31초 자유 감쇠, Welch(2048점, 분해능 0.098Hz), 8채널 평균.
- **f1 = 2.93Hz** (1차 수직 휨, 8개 센서 모두 최대 봉우리), f2 = 6.84Hz (2차, 역대칭).
- 손상·시험 주행은 이 값을 정할 때 보지 않았다.

## 3. v1과 달라지는 점
| 항목 | v1 | v2 | 이유 |
|---|---|---|---|
| GAT 그래프 | 모든 센서 연결 | 논문 규칙: 좌표 거리 d < d_th(10m)이면 연결, 자기 연결 포함 → 그림 16 행렬과 같음 | 논문과 같게 |
| Window 길이 | 128점 (0.64초 = f1 1.9주기, 분해능 1.56Hz) | **512점 (2.56초 = f1 7.5주기, 분해능 0.39Hz)** | f1 한 주기도 제대로 담지 못해 고유진동수 변화를 볼 수 없었다. 논문 Z-24 검증과 같은 2.56초 |
| Window 간격 | 4점 | 16점 (0.08초) | 계산량을 v1과 비슷하게 유지. 주행 단위 분할이라 결과 판단에 영향 없음 |
| 복원기 | 16점 → 전치 합성곱 3층(×8) → 128점 | 64점 → 같은 3층(×8) → 512점 | Window 길이에 맞춤. 나머지 구조·학습 설정은 v1 그대로 |
| Isolation Forest 주파수 특징 | 0–100Hz 8구간 (절대 Hz) | f/f1 기준 8구간: 0.5–1.5, 1.5–2.5, 2.5–3.5, 3.5–5, 5–7, 7–10, 10–15, 15–34 + 0.5–1.5 f1 구간 무게중심 주파수 / f1 | 크기가 다른 다리(HW)에 그대로 옮기기 위해 |
| 분할 | R1(주행 단위) + R0(논문식) | R1만 | R0가 원인이 아님을 v1에서 확인 (R0도 탐지 4% 이하) |
| 센서 구성 | S8, S2 모두 TCN-GAT·TCN·IF | S8: TCN-GAT·TCN·IF / S2: TCN·IF | S2(A1·A3)는 거리 14.75m > d_th라 논문 규칙으로는 연결이 없어 GAT가 의미 없다 |

바뀌지 않는 것: 데이터 구간(차량 통과 구간), 판정 대상(INT40·DMG1–3), 주행 번호 분할(학습 1–4 / 임계값 5–7 / 시험 8–10), 정규화, TCN(3층, 커널 32, 채널 64, 팽창 1·2·4), GAT(2층, 헤드 4, 은닉 64 → 8), 1×1 압축(채널 8), Adam 1e-3, 배치 32, 드롭아웃 0.3, 60 epoch, 손실 복원 MSE, 시드 20261126.

## 4. 임계값과 보고 항목
- 판정 임계값: 임계값 주행(5–7) Window 점수의 평균 + 3σ (v1·논문과 같음).
- 보고만: 임계값 주행 점수의 99% 분위수로 계산한 오경보·탐지율 (v1에서 평균 + 3σ가 중앙값의 25배로 커진 것을 보기 위해).
- Window 단위 오경보율, DMG1–3 각각·전체 탐지율, AUC. 주행 단위 이상 비율, RCV·INT30·INT50 이상 비율 (v1과 같음).

## 5. 판단 기준 (미리 정함)
- 통과: S8에서 시험 정상 오경보 ≤ 5% 그리고 DMG 전체 탐지 ≥ 80% (v1과 같음). 아니면 "통과 못 함".
- Window 효과: v2 TCN 단독(그래프 없음)의 AUC가 v1 TCN 단독(S8 R1 0.562)보다 0.05 이상 높으면 "Window 길이 효과 있음".
- 그래프 효과: v2 TCN-GAT가 v2 TCN 단독과 Isolation Forest보다 AUC가 0.02 이상 높으면 "좌표 그래프 효과 있음".
- 주파수 정규화 특징: v2 Isolation Forest AUC를 v1(S8 R1 0.544)과 비교해 보고한다.

## 6. HW로 옮기는 규칙 (v2가 통과하면 적용, 지금은 기록만)
| 항목 | Old ADA (v2) | HW (BOX·TRUSS 600mm) |
|---|---|---|
| 센서 위치 | x/L로 표기 (A1 = 0.25, A3 = 0.50) | LIS2DW12 L/4(150mm) = 0.25, L/2(300mm) = 0.50 → S2와 같은 배치 |
| 그래프 | d < d_th 규칙 | 센서 2개, 같은 규칙 적용 (HW에서 GAT 이점은 거의 없음) |
| Window | f1 7.5주기 | Window 점 수 = 7.5 × fs_HW / f1_HW (HW 고유진동수·샘플링 확정 후 계산) |
| 주파수 특징 | f/f1 구간 | 같은 f/f1 구간 |
| 기준값·임계값 | Old ADA 정상 | HW 정상 데이터로 다시 계산 (적용 방식 ③ 같은 구조 재학습) |

- 필요한 HW 값: 1차 고유진동수 f1_HW, 샘플링 fs_HW, 가진 방법. HW 담당에게 요청한 상태다.

## 7. 실행 전 순서
1. 이 문서 커밋.
2. 코드 `src/ai1_oldada_tcngat_v2.py` 작성 → 합성 점검 (`--test`). 그래프가 그림 16 행렬과 같은지 확인.
3. 실제 데이터 1회 실행 → `results/public/oldada_tcngat_v2/`.
- 예상 시간: S8 TCN-GAT·TCN 각 약 45분, S2 TCN 약 10분, IF 수 초 → 약 1시간 40분.
