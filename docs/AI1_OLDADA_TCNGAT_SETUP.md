# Old ADA TCN-GAT 실행 설정 (실행 전 기록)

작성일: 2026-11-26 · 작성: AI① · 근거: Ni et al. 2025, Sensors 25:6724, 3.2·4.3절, 표 6 · 코드: `src/ai1_oldada_tcngat.py`

Old ADA는 AI①이 예전에 다른 특징으로 다룬 데이터라 새 검증이 아니라 **논문 방법의 개발 시험**이다. 결과를 보고 아래 설정을 바꿔 다시 돌리지 않는다.

## 데이터
- `Old_ADA_Bridge-damage_vibration_data.mat`의 `VBA`. 열: 0 = 시간(200Hz), 1–8 = 가속도 8개, 9–11 = 광센서(진입·중간·진출).
- 쓰는 구간: 차량 통과 = 기록 시작(진입, t=0)부터 진출 광센서(11열) 첫 펄스까지.
- 40km/h만 판정에 쓴다 (손상 상태가 모두 40km/h). INT 40km 10회, DMG1 12회, DMG2 10회, DMG3 10회.
- 보고만: RCV 40km 10회, INT 30km 11회, INT 50km 5회 (속도가 다른 정상).
- Window 128점(0.64초), 간격 4점 (논문 그대로). 정규화는 학습 주행 Window의 채널별 평균·표준편차.

## 주행 단위 분할 (R1, 판정용)
| 역할 | INT 40km 주행 번호 |
|---|---|
| 학습 | 1–4 |
| 임계값 | 5–7 |
| 시험 정상 (오경보) | 8–10 |

기존 `config.OLD_ADA["int40_split"]`과 같은 번호다. 같은 주행의 Window가 두 역할에 들어가지 않는다.

## 논문식 분할 (R0, 비교용)
- INT 40km 10회의 모든 Window를 무작위 8:2로 나눠 학습·검증. 임계값과 오경보는 검증 Window로 계산. 논문의 누수 효과를 보기 위한 것이다.

## 모델 (3개, 같은 입력·분할·임계값 규칙)
| 모델 | 구조 |
|---|---|
| TCN-GAT | 센서별 공유 TCN 3층(커널 32, 채널 64, 팽창 1·2·4, 인과) → 1×1 합성곱으로 채널 8 (시간 128점 유지) → GAT 2층(헤드 4, 은닉 64 → 8) → 선형 → 전치 합성곱 3층으로 128점 복원 |
| TCN 단독 | 위에서 GAT 대신 선형층(같은 출력 크기) |
| Isolation Forest | 채널별 rms, p2p, 첨도, 0–100Hz 8구간 로그 에너지 (채널당 11개). 나무 300개 |

- 학습 (TCN-GAT, TCN 단독): Adam, 학습률 1e-3, 배치 32, 드롭아웃 0.3 (표 6. 학습률만 다름, 아래 참고), 60 epoch 고정, 기울기 자르기 1.0, 손실 = 복원 MSE. 조기 종료 없음.
- 그래프: 논문은 센서 좌표 거리로 인접 행렬을 만들었으나 좌표를 확인할 수 없어 **모든 센서를 연결**(자기 연결 포함)하고 주의 가중치를 학습한다. 논문과 다른 점이다.
- 점수: 신경망은 Window 복원 MSE, Isolation Forest는 `-score_samples`.
- 임계값: 임계값 역할 Window 점수의 평균 + 3σ (논문 규칙).

## 센서 구성
| 이름 | 채널 | 목적 |
|---|---|---|
| S8 | 1–8열 전체 | 논문 조건 |
| S2 | 1열(A1, L/4), 3열(A3, L/2) | 센서 2개로 **재학습이 되는지** 확인. 위치가 HW와 같을 뿐 HW 성능 근거로 쓰지 않는다 |

## 보고 항목
- Window 단위: 시험 정상 오경보율, DMG1–3 각각과 전체 탐지율, AUC (시험 정상 대 DMG1–3).
- 주행 단위 (보고만): Window 절반 넘게 이상이면 그 주행을 이상으로 본다.
- 보고만 데이터(RCV, INT 30·50km)의 이상 비율.
- 난수 시드 20261126. CPU 1회 실행.

## 판단 기준 (미리 정함)
- 시험 정상 오경보 ≤ 5% 그리고 DMG 전체 탐지 ≥ 80%이면 S8 원 교량 검증 "통과", 아니면 "참고용".
- TCN-GAT가 TCN 단독과 Isolation Forest보다 AUC가 0.02 이상 높지 않으면 GAT의 효과는 확인되지 않은 것으로 적는다.

## 실제 데이터 실행 전 합성 점검에서 바꾼 점 (2026-11-26)
실제 Old ADA 결과를 보기 전에 합성 데이터(정상 7·40Hz, 손상 7·30Hz)로 코드를 점검하다 바꿨다.
1. 학습률 5.68e-3 → 1e-3: 논문 값에서는 손실이 1.0(출력이 항상 0)에 머물러 학습이 되지 않았다. 1e-3에서는 손실이 내려갔다.
2. 시간 16구간 평균 → 1×1 합성곱(채널 8, 시간 유지): 8샘플 평균이 40Hz 성분을 지워 신경망이 합성 손상을 구분하지 못했다 (AUC 0.63). 바꾼 뒤 AUC 1.00.
3. 합성 손상을 23→19.6Hz에서 40→30Hz로 바꿨다: Isolation Forest 특징의 같은 주파수 구간에 들어가 점검이 되지 않았다.

진행 상황은 터미널과 `results/public/oldada_tcngat/progress.log`에 epoch마다 찍힌다.
