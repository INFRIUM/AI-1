# D1. LUMO 조건부 PCA + MEWMA (함부르크 방법) — 실행 설정 (실행 전 기록)

작성일: 2026-11-28 · 작성: AI① · 코드: `src/ai1_lumo_cpca.py` · 근거: Neumann, Mendler, Wittenberg, Gertheiss 2026 (arXiv 2604.00662), 3.1–3.3절, 4절

함부르크 교량 데이터는 공개되지 않아, 같은 센서 종류(변형률 + 온도)의 공개 데이터 LUMO에 논문 방법을 적용한다. 변형률 + 온도 전문 모델(D)이다. 현재 HW에는 변형률 센서가 없어 HW 적용은 판정 보류(④).

- LUMO는 AI①이 가속도로 평가한 적이 있다 (손상 구간·라벨을 앎). **변형률 값은 이번에 처음 본다** (설계 중 본 것은 2020-08-01 처음 3개 블록 값뿐). 결과를 보고 설정을 바꿔 다시 돌리지 않는다.
- LUMO는 교량이 아니라 강 격자 철탑이다. 손상은 볼트로 부재를 바꿔 끼운 가역 손상이다.

## 1. 논문 방법 (확인한 것)
- 변형률 6개 + 재료 온도 1개를 **1시간 평균**으로 쓴다.
- Phase I(정상)으로 온도 z에 따른 조건부 평균 m(z)와 조건부 공분산 Σ(z)를 커널로 추정한다. 조건부 PCA로 온도 영향을 평균·공분산 모두에서 없앤 특징을 다시 만든다: x̃ = x̄ + A Λ^½ Λ(z)^−½ A(z)ᵀ (x − m(z)).
- 비교 방법은 두 가지다.
  - 비지도: 온도를 쓰지 않는 PCA
  - 부분(partial): 평균만 온도로 보정
- 감시: MEWMA 관리도, κ = 0.2. 임계값 h4는 Phase I을 하루 단위 블록 부트스트랩해 ARL0 = 720시간(30일)이 되도록 정한다.
- 논문 결과: 조건부 방법만 추가 질량을 잡았다. 학습 범위 밖 온도에서는 오경보가 났다.

## 2. 데이터
- `lumo/meta_struct/SHMTS_YYYYMM_meta_struct.mat` 12개 (2020-08 – 2021-07). 10분 블록 통계 `mean-strain01–03`, `mean-temp01`과 상태 코드(정상 2, 손상 3, 기타 1).
- 1시간 평균: 정시 기준 1시간 안 10분 블록 평균. 블록 4개 미만인 시간은 뺀다.
- 상태 코드 1인 시간, 그리고 상태가 바뀌는 시각 앞뒤 6시간은 뺀다 (부재 교체 작업).
- 손상 구간 이름은 `lumo/lumo_v4_blocks.csv`의 구간(cv_group) 시각으로 붙인다.

| 역할 | 기간 |
|---|---|
| **Phase I (학습)** | 정상 N1: 2020-08-01 – 10-09 |
| Phase II 정상 (오경보) | N2 (10-27 – 11-09), N3 (11-24 – 03-18, 겨울), N4, N5, N6, N7 |
| Phase II 큰 손상 (탐지) | DAM6_111 (2020-10), DAM4_111 (2020-11), DAM3_111 (2021-03 – 04) |

## 3. 계산
1. x = [strain01, strain02, strain03] (1시간 평균), z = temp01 (1시간 평균).
2. 커널: 가우스, 대역폭 h = Silverman 규칙 (Phase I z). m(z) = Nadaraya–Watson 평균. Σ(z) = 가중 공분산 (잔차 x − m(z)).
3. 조건부 방법: 위 식으로 x̃. A, Λ는 Phase I 잔차의 일반 PCA. Phase I 범위 밖 온도는 커널 가중 그대로 (가장 가까운 Phase I 온도 쪽 값에 가까워짐, 외삽 보정 없음).
4. 부분 방법: x̃ = x̄ + (x − m(z)). 비지도 방법: x̃ = x.
5. MEWMA: Phase I x̃의 평균 μ0·공분산 S로 표준화. Zᵢ = κ(x̃ᵢ − μ0) + (1 − κ)Zᵢ₋₁, Z₀ = 0, Tᵢ² = Zᵢᵀ (κ/(2 − κ) S)⁻¹ Zᵢ. 시간 순서대로 연속 계산 (뺀 시간은 건너뜀).
6. h4: Phase I x̃를 하루 단위로 나눠 복원 추출로 이어 붙인 수열에서 MEWMA 첫 경보까지 시간의 평균이 720시간이 되는 값. 2,000번 반복 (논문 100,000번보다 적음), 이분 탐색.
7. 비교: Isolation Forest (1시간 [strain01–03, temp01], Phase I 학습, 임계값 = Phase I 점수 99% 분위수, 시간 단위 판정).

## 4. 보고 항목
- 방법별, 구간별 경보 시간 비율. Phase II 정상 전체 오경보율, 큰 손상(111) 전체 탐지율, 작은 손상(010) 탐지율.
- 구간별 온도 범위 (Phase I 범위 밖 시간 비율).

## 5. 판단 기준 (미리 정함)
- 조건부 방법: Phase II 정상 오경보 ≤ 5% (시간 기준) 그리고 큰 손상 탐지 ≥ 80%이면 "통과", 아니면 "통과 못 함".
- 조건부 방법이 부분·비지도·Isolation Forest보다 (탐지율 − 오경보율)이 0.05 이상 높지 않으면 "조건부 보정이 낫다는 근거 없음".
