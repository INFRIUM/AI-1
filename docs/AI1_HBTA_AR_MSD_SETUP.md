# HBTA AR(5) + MSD 재현 설정 (실행 전 기록)

작성일: 2026-11-26 · 작성: AI① · 근거: Svendsen et al. 2021, J. Civil Struct. Health Monit. 12:101–115 (doi 10.1007/s13349-021-00530-8), 3·4.3·4.4절 · 코드: `src/ai1_hbta_ar_msd.py`

HBTA는 결과를 이미 본 데이터라 새 검증이 아니라 **논문 재현과 개발 시험**이다. 결과를 보고 아래 설정을 바꿔 다시 돌리지 않는다.

## 데이터
- `data_100Hz.h5`의 진동기 노이즈 가진 측정 `MVS_P2_*_NM_Z_*` 10개: UDS1 = `UDS_NM_Z_01`, UDS2 = `UDS_NM_Z_02`, DS1–DS8 = `DS{k}_NM_Z_01`.
- 측정마다 90초부터 10.24초(1,024샘플) Window를 겹치지 않게 80개 (논문: 상태당 80개). 90초는 기존 처리와 같은 가진 안정 구간 시작.
- 센서 그룹 1 = `AL01`–`AL40` z (40채널), 그룹 2 = `AG01`–`AG18` y·z, `AG09`는 z만 (35채널).

## 특징과 탐지 (논문 그대로)
- 채널마다 평균을 뺀 뒤 AR(5) 계수를 최소제곱으로 추정 → 그룹 1은 200차원, 그룹 2는 175차원.
- 학습: UDS1·UDS2에서 각각 앞 40개 Window(80개) → 20번 복사, 각 특징에 잡음(표준편차 = 그 특징 절댓값 평균 ÷ 20)을 더함 → 1,600개.
- 점수: 학습 평균·공분산으로 마할라노비스 거리 제곱(MSD).
- 기준: 학습과 같은 크기의 표준정규 행렬로 MSD 최댓값을 1,000번 구해 상위 1% 값.
- 시험: UDS1·UDS2 나머지 40개씩(80개) + DS1–DS8 80개씩(640개).

## 함께 볼 시험 (논문에 없음, 설정 고정)
| 이름 | 바꾼 점 | 보는 것 |
|---|---|---|
| R1 재현 | 위 그대로 | 논문 표 5 (그룹 1: 오경보 6.3%, 놓침 4.1% / 그룹 2: 48.8%, 0.0%)와 비교 |
| R2 센서 2개 | 특징만 `AG03`, `AG05`의 y·z (20차원). 나머지는 R1과 같음 | 축소 교량처럼 센서가 적을 때 |
| R3 따로 잰 정상 | 학습은 UDS1 앞 40개만, 시험 정상은 UDS2 80개 전부 | 학습에 쓰지 않은 정상 측정에서 오경보 |

R2·R3는 그룹 1·2와 센서 2개에 모두 적용한다. 보고 항목: 오경보율, 손상별·전체 놓침, AUC.

## 추가: Isolation Forest 비교 (2026-11-26, 실행 전 기록)
모든 전문 모델은 Isolation Forest와 비교한다는 #25 합의에 따라 추가한다. AR+MSD 결과(`summary.csv`)는 바꾸지 않는다.
- 입력: 위와 같은 AR(5) 특징, 같은 그룹(1·2·센서 2개), 같은 시험 R1·R2·R3, 같은 학습·시험 Window.
- 학습: 잡음 증강 없이 학습 Window 그대로 (R1·R2 80개, R3 40개). 증강은 공분산 안정용이라 Isolation Forest에는 쓰지 않는다.
- 모델: `config.IFOREST` 설정 (나무 200개, random_state 42). 점수 = `-score_samples`.
- 임계값: 학습 Window 점수의 99% 분위수 (`config.IFOREST["threshold_quantile"]`). 보조 z 규칙은 쓰지 않는다.
- 결과: `results/public/hbta_ar_msd/iforest_summary.csv`, `iforest_by_state.csv`. 보고 항목은 AR+MSD와 같다.
- 코드: `src/ai1_hbta_iforest.py`. 결과 파일이 있으면 다시 실행하지 않는다.
