# E1 v2. Ponte Moesa 1-TAC (10분 평균 전달률) — 실행 설정 (실행 전 기록)

작성일: 2026-11-28 · 작성: AI① · 코드: `src/ai1_moesa_tac_v2.py` · v1 설정 `docs/AI1_MOESA_TAC_SETUP.md` · v1 결과 `results/public/moesa_tac/`, 조건표 9절

v1(1회)은 개발 시험 통과 못 함 (DS3–7 탐지 1.4%, AUC 0.637). v1 결과는 그대로 둔다. v1에서 60초 구간 하나의 전달률 추정 잡음이 손상 차이보다 컸다 (기준 구간끼리도 1-TAC 중앙값 0.55). v2는 **여러 구간의 스펙트럼을 평균해 전달률을 안정시키는 것**만 바꾼다. 개발 시험이다. 결과를 보고 설정을 바꿔 다시 돌리지 않는다.

## 1. v1과 달라지는 점
| 항목 | v1 | v2 | 이유 |
|---|---|---|---|
| 판정 단위 | 60초 구간 1개 | **10분 묶음** = 같은 측정 안에서 이어진 유효 60초 구간 10개. G_ab·G_bb를 합한 뒤 전달률 계산 | 추정 잡음 감소 (Welch 조각 약 10개 → 약 110개) |
| TAC 벡터 | 복소 전달률 | **크기 |T|** (실수 벡터) | 위상 추정 잡음 제외. 논문 식의 전치(ᵀ) 표기와도 맞음 |
| 남는 구간 | – | 측정 끝의 10개 미만 구간은 버림. 10개 미만 측정은 묶음 없음 | |
| Isolation Forest 특징 | 구간 log|T| | 묶음 log|T| (같은 27개) | 같은 조건 비교 |
| (보고만) | 고유진동수 f1 | 복소 1-TAC (10분 묶음) | 평균 효과와 크기 사용 효과를 나눠 보기 위해 |

바뀌지 않는 것: 고정 센서 1·2·3번 Z축, 쌍 P12·P23·P13, 2–25Hz 대역 통과, Welch 2048점, 3–12Hz, RMS ≤ 0.008g 구간 규칙, 측정 역할(기준 AMB_10 / 임계값 AMB_11 / 시험 정상 AMB_12–18 / 손상 DS3–7 / 보고만 AMB_1–9), 임계값 = 임계값 역할 점수의 99% 분위수, 결합 점수 = 세 쌍 평균.

## 2. 묶음 수 (측정 목록 길이로 미리 계산, 유효 구간이 줄면 더 적어짐)
- 기준 약 29, 임계값 약 30, 시험 정상 약 28 (대부분 AMB_18), DS3 약 85, DS4 약 8, DS5 약 6, DS6 약 83, DS7 약 1.
- 묶음이 적어 오경보 5%는 시험 정상 묶음 1개 정도다. DS7은 묶음 1개라 따로 판단하지 않고 전체에만 넣는다.

## 3. 판단 기준 (미리 정함)
- 결합 점수: 시험 정상 오경보 ≤ 5% 그리고 DS3–7 전체 탐지 ≥ 80%이면 "개발 시험 통과", 아니면 "통과 못 함" (v1과 같음).
- 평균 효과: v2 결합 AUC가 v1(0.637)보다 0.05 이상 높으면 "10분 평균 효과 있음".
- E1 v2가 Isolation Forest(같은 묶음)보다 결합 AUC가 0.02 이상 높지 않으면 "비교 기준보다 낫다는 근거 없음".
- 쌍별(HW 형태) 결과를 따로 적는다.

## 4. HW로 옮길 때
- 판정 단위가 10분이 된다. HW 상시 진동 계측이면 10분 이상 연속 기록이 필요하다. 타격 가진이면 같은 묶음에 여러 번 타격을 모아 평균한다.
